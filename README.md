# mcp-ssh

`mcp-ssh` は、AIエージェントがSSHコマンドを実行するための軽量なMCPアダプターです。
本ツールは、GUI管理ハブである [**mcp-ssh-manager**](https://github.com/veltrea/mcp-ssh-manager) と対になる存在であり、**この2つが揃うことで初めてAI時代のセキュアなリモート操作が完結します。** 開発の便宜上リポジトリは分かれていますが、これらは一つのエコシステムの両輪として設計されています。

## 1. 役割
- **AI向けインターフェース**: JSON-RPCを介してAIからの指示を受け取ります。
- **セキュリティ・ゲートウェイ**: エイリアス経由のみに限定し、実行前にDB制約を評価します。未知の制約ルールは fail-close で拒否します。
- **監査ログの記録**: 実行されたすべてのコマンドを `manager.db` に記録します。

## 2. コマンドライン (CLI) モード
本アダプターは、人間がターミナルから直接利用することも可能です。AIが実行するのと同じ安全なパス（制約チェック、ログ記録）を通ります。

### 2.1. SSH コマンドの実行 (exec)
```bash
# エイリアス my-server でコマンドを実行
cargo run -- exec my-server "ls -la"
```

### 2.2. ホスト情報の表示 (info)
```bash
# マシンのコンテキストと制約を表示
cargo run -- info my-server
```

### 2.3. MCP モード (mcp)
JSON-RPC を介した MCP サーバーとして起動します（引数なしでも同様）。
```bash
cargo run -- mcp
```

## 3. 提供ツール (MCP)
AIエージェントには以下のツールが提供されます：
リモートホストでコマンドを実行します。
- **alias (推奨)**: `mcp-ssh-manager` に登録されたエイリアスを指定。この場合、制約チェックと自動ログ記録が行われます。
- **command**: 実行するコマンド文字列。

### 2.2. `get_host_info`
接続先マシンの詳細情（用途、制約、OS、所有権）を取得します。接続前にAIが適切な判断を行うために必須のステップです。

## 3. 実行フロー
1. AIが `get_host_info` でマシンの制約を確認.
2. 問題がなければ `ssh_exec` をエイリアス指定で実行。
3. `mcp-ssh` がDB上の制約を評価し、許可された場合のみ続行。
4. 内蔵 SSH 実装（`ssh2`）で接続・実行。
5. 成功・失敗に関わらず結果がManagerのログに記録される。

## 4. 設定
`mcp-ssh-manager` と同じデータベースを参照するため、特別な追加設定は不要です。
